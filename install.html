Get Arcade as an App

Same arcade, but as a real installed app — fullscreen, no browser bar, home-screen icon, works offline for saved games.

🚀 FullscreenNo browser chrome — game cards take the whole viewport.
🏠 Home-screen iconTap the Arcade icon, you're in. Like any native app.
📡 Offline-friendlySaved games work without a connection.
🔔 Push-readyFuture feature: notifications when friends are playing.

🤖 Android (Chrome / Edge / Brave)

  1. Tap the big Install button above. Chrome's native install dialog pops up.
  2. Confirm. The Arcade icon appears on your home screen + app drawer.
  3. Launch from there — no address bar, looks/behaves like a native app.

Don't see the install button? Chrome unlocks installation after ~30 seconds of engagement. Browse a few games and try again — or use ⋮ → Install app from Chrome's menu directly.

📦 Android — Real APK file

Want an actual .apk file you can sideload (no Chrome required, fully sandboxed)?

  1. Open PWA Builder
  2. Paste your Arcade URL (e.g. https://computerscience-lessons.onrender.com)
  3. Click Package for Android → download the signed APK
  4. On your phone: enable Install from unknown sources in Settings, tap the APK → install.

PWA Builder is a free Microsoft tool. The output is a real signed APK that wraps the live Arcade in a Trusted Web Activity — fully native install path with no Chrome dependency.

🍎 iPhone / iPad (Safari)

  1. Open this site in Safari (not Chrome — Apple only allows Safari to install web apps).
  2. Tap the Share button (square with up arrow at the bottom).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top-right.

After install, Arcade opens fullscreen from your home screen with no Safari UI — looks like a native iOS app.

💻 Desktop (Chrome / Edge / Brave)

  1. Look for the small install icon in your URL bar (right side, looks like a monitor with a down-arrow).
  2. Click it → Install.
  3. Arcade gets its own dock/taskbar icon and launches in a standalone window.

Or use the menu: ⋮ → Install Arcade… on Chrome/Edge.
